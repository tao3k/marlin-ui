#+title: Marlin UI — Doom Emacs Desktop, Mobile, and Web Client for Marlin Agent Core
#+filetags: :tao3k:marlin:ui:emacs:desktop:mobile:wasm:grpc:sysml:

=marlin-ui= is the official three-platform release client for
[[https://github.com/tao3k/marlin-agent-core][Marlin Agent Core]], built as a
pure-Go (=CGO_ENABLED=0=) native UI shell over the
[[https://github.com/tao3k/marlin-mygo][marlin-mygo]] headless engine library.

* Architecture & Deterministic-Engineering Contract

Architecture ownership, package boundaries, and state machines are declared in
OpenSysML v2 at the repository root:

- [[file:project.sysml][project.sysml]]: Top-level project model entry and named architecture views.
- [[file:dev/sysml/README.org][dev/sysml/README.org]]: Model map, requirement traceability, and strict validation commands (=just sysml-check=).
- *Hard Go Pure-Frontend Constraint (=MUI-ARCH-R04=)*: Rust (=marlin-agent-core=)
  owns 100% of the agent Runtime backend (LLM dispatch, tool execution, SQL/Turso
  storage, gRPC/HTTP servers, process execution). Go in =marlin-ui= is strictly a
  native UI shell and thin gRPC projection client — mechanically enforced by
  =internal/archguard/boundary_test.go= (=just check-go-boundary=).
- *Headless Library Separation (=MUI-ARCH-R01=)*:
  [[https://github.com/tao3k/marlin-mygo][marlin-mygo]] supplies headless engines
  (=TranscriptController=, 120Hz =Helm= search, =PromptGate=, =AuthManager=,
  =WorkbenchController=, gRPC wire), while =marlin-ui= owns its Doom Emacs
  design system and hierarchical UI under =internal/emacs/*=.

* Hierarchical Doom Emacs Package Structure (=internal/emacs/*=)

Declared 1:1 in [[file:dev/sysml/emacs-workbench.sysml][dev/sysml/emacs-workbench.sysml]] (=MUI-EMACS-A01=..=A08=) and
enforced acyclic by =just check-go-boundary=:

| Package | SysML Part | Responsibility |
|---------+------------+----------------|
| =internal/emacs/theme= | =MUI-EMACS-A02= | Governed CSS theme packs (=nord-bento=, =doom-one=, =doom-tokyo-night=, =doom-one-light=), =~/.config/marlin/ui/= cascade, live =marlin.ui.v1= =UITheme= projection, soft-rounded primitives |
| =marlin-mygo/runtime/{kit,widgets}= | =MUI-EMACS-A10= | Upstream GPU framework & EWW-inspired Bento widget engine: overflow-proof typography/layout primitives, iOS 26 Liquid Glass surfaces, SF Symbols, Kage GPU shaders, reactive =Signals=, dual TOML/S-expression parsers, =*Dashboard*= & immersive =zen-mode= |
| =internal/emacs/meow= | =MUI-EMACS-A03= | Meow modal state (=INSERT=, =NORMAL=, =SPC= Keypad leader) and universal Emacs shortcuts |
| =internal/emacs/tabs= | =MUI-EMACS-A04= | Centaur-Tabs bar (28px, 2px active top accent bar) |
| =internal/emacs/window= | =MUI-EMACS-A05= | Full-bleed primary Emacs Window viewport + inline Tier-0 =GATE= approval strip |
| =internal/emacs/buffer= | =MUI-EMACS-A06= | Categorized major modes: =*conversation*= (Doom Dashboard + stream), tabulated buffers (=*Sessions*=, =*Targets*=, =*Processes*=, =*Models*=, =*Messages*=, =*Help*=), and =*Settings*= customize buffer |
| =internal/emacs/modeline= | =MUI-EMACS-A07= | Authentic 24px Doom Modeline with 3px colored state bar, live gRPC model/session/status |
| =internal/emacs/minibuffer= | =MUI-EMACS-A08= | Single-line Emacs Minibuffer & Echo Area, inline Vertico (=M-x= merging live =marlin.ui.v1= commands), 120Hz Helm, Keypad Which-Key |
| =internal/emacs/frame= | =MUI-EMACS-A01= | Top-level 4-region Doom Emacs Frame composition and live =marlin.ui.v1= gRPC synchronization |

* Three Release Targets

| Target  | Entrypoint           | Platforms                                 | Native Capabilities                                                        |
|---------+----------------------+-------------------------------------------+----------------------------------------------------------------------------|
| Desktop | =cmd/marlin-desktop= | macOS (arm64/amd64), Linux, Windows       | Doom Emacs Frame + HTTP/2 gRPC + OS Keychain Vault + Native Menu/Tray + Voice/Files |
| Mobile  | =cmd/marlin-mobile=  | iOS (Apple HIG 393x852), Android (M3)     | mTLS/TLS 1.3 gRPC + OS Vault + QuickCapture + App Store 2.5.2 OTA Packs    |
| Web     | =cmd/marlin-web=     | Browser WebAssembly (=GOOS=js GOARCH=wasm=) | Responsive Desktop/Phone + =localStorage= Continuity & Prefs + Helm =Cmd+P= |

* Build, Packaging & Verification Gates

#+begin_src shell
# Full verification gate (tests, -race, Go frontend boundary guard, feature pruning, file-size, sysml-check, vet)
just check

# Validate OpenSysML v2 architecture models strictly
just sysml-check

# Verify hard Go pure-frontend & acyclic Emacs package boundary
just check-go-boundary

# Minimal core client (zero optional features linked)
just build-desktop marlin_minimal ./dist/marlin-desktop-core

# Full client across Desktop, Mobile, and Web WASM (ChatRoom + Compare + Canvas)
just build-all marlin_full

# Package a self-contained macOS Marlin.app bundle
just package-macos-app marlin_full ./dist/Marlin.app
#+end_src

* Connecting to Marlin Agent Core (gRPC)

#+begin_src shell
# Print release build metadata
./dist/marlin-desktop -version

# Connect Desktop to a remote TLS 1.3 / mTLS Rust marlin-app-server
./dist/marlin-desktop -host core.example.com:50051 -ca ./ca.pem

# Local DEV-ONLY helpers (isolated strictly to Justfile, never in Go binaries)
just dev-desktop
just dev-test-rust
#+end_src
