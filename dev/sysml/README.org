* Scope and deterministic-engineering contract

This directory owns the authored OpenSysML v2 architecture models for
=marlin-ui=, following the =deterministic-engineering= architecture content
contract:

- =project.sysml= at the repository root is the single top-level entry point
  exposing named architecture and lifecycle views.
- Every model separates =actual= (source-inspected Go packages) from =target=
  (planned structural evolution) without claiming target work as implemented.
- Every element uses stable short IDs (=MUI-PROJECT=, =MUI-ARCH-*=,
  =MUI-EMACS-*=), directed consumer-to-supplier dependencies, and explicit
  requirement allocations.
- Every Go package under =internal/emacs/= maps 1:1 to a declared structural
  part in =dev/sysml/emacs-workbench.sysml=.

* Validate and render

Run strict validation from the repository root:

#+begin_src sh
just sysml-check
#+end_src

Which executes:

#+begin_src sh
sysml -strict -validate -self-check -no-record-cache project.sysml dev/sysml
#+end_src

Generated diagram outputs stay under =dist/sysml/= (ignored by Git); only
authored =.sysml= and =.org= sources live in version control.
